## 尚未真实端到端验收的环节

1. **GitHub Trending 网页采集**：采集器和解析器已实现，但真实网站可能随时变更 DOM 或对请求频率实施限制，需在用户网络环境运行并检查运行日志。
2. **闲鱼/小红书/1688 平台自动同步**：需要用户自行获得有权使用的数据源，并提供 HTTPS 适配接口；没有账号授权就不会返回站内实时商品和笔记。
3. **Windows Task Scheduler**：当前验收环境非 Windows，安装脚本需要在用户机器上验证。
4. **实际 X API**：仍取决于官方开发者权限与费用；未绑定则禁用。

## Windows 上升级后的验收步骤

1. 运行 `backup_windows.bat`，确认备份文件；保留旧 `.env` 和 `DATA_DIR`。
2. 覆盖源码并双击 `run_windows.bat`；打开设置，检查 8 张卡、间隔能保存，旧机会和实验仍存在。
3. 在 `GitHub Trending` 卡上保持启用，前往「情报源中心」点该卡的「强制刷新」，等待后检查来源日志；无结果时读取失败原因而非看到虚假数据。
4. 提供一份来源合规的 CSV，选择闲鱼/小红书/1688 中的对应平台，导入后到「机会雷达」筛选并查看原始链接。
5. 若已有授权适配器，填写 URL、启用并选择 24 小时，强制刷新一次，再观察未到期的下次后台检查没有重复请求。
6. 运行 `install_due_task.ps1`，打开 Windows 任务计划程序确认 `Opportunity OS Due Scan` 的每小时触发，检查旧任务没有重复执行。
