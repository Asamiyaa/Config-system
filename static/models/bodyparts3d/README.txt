Model assets are downloaded on the user's Windows machine by:
  python scripts/setup_anatomy_assets.py

Source: jixiangying/skeleton, based on BodyParts3D / Anatomography.
License: CC BY-SA 2.1 Japan. Attribution notice is generated as ATTRIBUTION.txt after download.
The binary model files are not bundled in this patch because this execution environment cannot fetch binary assets from GitHub. Run the setup script once with internet access; thereafter the model viewer uses local files.
