# Scenario 37 — 图片画布拖拽与平移

> 类型：拖拽与手势 · 用途：可平移大画布但不失选中目标 · 关键词：Canvas Pan / 画布 / 节点编辑

**本文件是可直接交给 Codex 执行的交互契约。先读 `AGENTS.md`、`.agents/design/UX_FOUNDATIONS.md`、`MOTION_SPEC.md`、`SCENARIO_PROMPT_SCHEMA.md`，不要机械套用不匹配的库或组件。**

## 直接交给 Codex 的专属指令

```text
目标：可平移大画布但不失选中目标
触发条件：按空格+拖动或空白处拖动
起点/终点/分层编排：画布统一transform平移，网格和节点坐标同一世界矩阵
精确节奏：拖动跟手，松开可选择小幅阻尼但不假改数据
反向/撤销：反向按同世界坐标移动；重置回明确初始视图
异常/中断/业务约束：缩放后坐标换算、边界夹取、多指冲突
专属验收：pan→zoom→pan→reset，精确点击节点与坐标

执行方式：先检测当前仓库的组件、路由、技术栈和权限/数据状态；
明确触发元素 stable id、初始态、结束态、时间轴单一控制源、可逆条件及完成状态；
然后在真实业务组件实现（不只是孤立 Demo），验证桌面/移动/键盘/触屏/减少动态效果；
提供操作前后及关键中间帧证据，并给出失败/取消/快速反向的实际测试结果。
```

## 专属交互规格

| 验收字段 | 本场景必须落实 |
|---|---|
| 用户任务与动作 | 可平移大画布但不失选中目标；由「按空格+拖动或空白处拖动」发起 |
| 状态和连续几何 | 画布统一transform平移，网格和节点坐标同一世界矩阵 |
| 时间与曲线 | 拖动跟手，松开可选择小幅阻尼但不假改数据；**原则：非线性、克制、主容器先于辅助** |
| 正向/逆向 | 反向按同世界坐标移动；重置回明确初始视图 |
| 中断和错误 | 缩放后坐标换算、边界夹取、多指冲突 |
| 无障碍 | 键盘与屏幕阅读器语义、焦点可达；reduced-motion 下直接落到同一正确结束状态 |
| 业务真实性 | 状态与数据由真实项目的用户行为、路由、请求和真实数据决定，不能伪造 |

## 推荐实现技术（有条件选择）

优先已有 dnd-kit、SortableJS 或 Motion Reorder；仅简单列表可使用原生 pointer+FLIP；React Reorder.Group 适合简单单列排序，复杂跨列不盲用。

**实施注意：** 在真实 DOM/图形场景中实际测量目标几何，避免硬编码对不齐；如果原框架有既有动画库优先复用。API 或库不具备能力时，保持语义正确的静态降级，不要为了视觉效果损坏核心任务。

## 本场景必须跑的专项验收

- **行为断言：** pan→zoom→pan→reset，精确点击节点与坐标。
- **中断测试：** 在运动进度约 40% 时再触发反向/重复，观察是否从当前状态继续并清理旧控制器。
- **状态正确：** 若当前操作不可逆或与真实网络结果关联，不能为了追求“反向对称”而伪造业务逆操作；只逆转可逆的视觉层。
- **多模态：** 390×844 与 1440×900、Tab/Enter/Escape（按组件语义）、触控、prefers-reduced-motion。
- **可观测：** 记录至少开始、完成、反向、异常 4 个状态的 DOM/截图或可复现日志；验证失败如实报告。

## Codex 实施顺序（强制）

1. **查现状：** 确认真实项目路径、当前框架与依赖、用户任务、页面/路由、业务状态、无障碍模式；不要凭文档猜组件名。明确哪些细节使用原有组件。
2. **写交互契约：** 按本配方固定触发源、唯一业务 key、初始/结束几何、主子时序、动画进度控制器、反向与取消。分清 UI 语义状态、异步业务状态与视觉进度，不把它们混在一个布尔值里。
3. **实现最小完整闭环：** 真实点击/键盘入口 → 动效及状态更新 → 成功或失败 → 撤销/关闭/返回；保留已有 API、权限、数据来源与 URL。只选一套动画引擎控制同一属性。
4. **处理异常与降级：** 连续点击、反向中断、组件卸载、Resize、异步先后顺序、无权限/无数据、prefers-reduced-motion、键盘/触摸、非支持浏览器。清理 observer/RAF/事件监听/动画/GPU。
5. **真实验收：** 在浏览器跑本配方专用测试；分别拍静态起始、关键中间帧、完成、反向和异常状态；记录实际测到的数据/日志。若环境无法做浏览器验收，标记未验证，不得声称视觉合格。

## 通用验收拒收项

- 页面初始自动入场、无意义呼吸/漂浮/粒子、全部元素同时淡入、抽象伪物理弹跳。
- 正反路径不一致且没有功能性解释；快速中断后出现幽灵层、覆盖层、重复提交、焦点丢失。
- 用 mock 进度 / mock 行情 / 假成功状态掩盖真实失败；以截图代替用户可操作的实现。
- 只完成桌面鼠标效果，忽略触摸、键盘、窄屏和 reduced-motion。
