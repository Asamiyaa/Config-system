# Prompt 03 — 严格视觉审查与迭代

停止增加新功能，进入 Visual QA + Art Direction 修正阶段。

启动项目，在真实浏览器截图并测试首屏静止状态、主要交互后状态、完整反向状态、移动端和 reduced-motion。按重要性列出最影响质量的 5 个问题；每个说明：**证据 → 原因 → 修复 → 重新验收方式**。

先审核：主页是否功能堆砌？是否信息过载？UI 风格是否统一？核心操作通常能否 2～3 次点击抵达？用户每次操作是否有即时、真实、可恢复的反馈？
逐条核对动效六原则：连续形变、物理缓动、分层时序、用户主动触发、正反完全对称、小幅精密微交互。检查快速反向、重复操作和静止首屏，无意义自动入场一律删除。

优先修：信息层级、构图/对齐、字体/间距、转场节奏、交互反馈。最后才考虑装饰。拒绝通用蓝紫渐变、同质圆角卡片、统一上移淡入、无意义持续特效。

直接修改并复测；列出截图路径、真实执行的检查以及失败项，切勿虚报评分与测试结果。

场景专项审核：根据 `.agents/scenarios/INDEX.md` 中实际选出的编号，打开对应场景的专属验收表逐项检查。原 01/02/03 仍要求封面ID/400ms、导航0/25/50/75/100px插值和按钮80/120ms；其余场景以各自契约为准。不接受“看起来很顺畅”作为证据。
