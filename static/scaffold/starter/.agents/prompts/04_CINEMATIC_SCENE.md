# Prompt 04 — 电影级空间交互

为 [填写场景] 编排一个**必须用户主动触发**、可反向的电影式交互，而不是自动播放的视频。

请先确定：
- 用户为什么需要 3D？不能用 2D 完成的空间关系是什么？
- 镜头的开始位置、目标、结束位置、可操作范围和安全约束。
- Timeline（建立场景 / 物体变化 / 材质光照 / 镜头移动 / 自由操作）。
- 初始页面必须静止，用户点击 Play/Transform 才能进入动画；不自动播放也不自动循环。
- 入口、暂停、拖动时间轴、回放、反向、跳转和快速重复操作如何处理。
- 形变保留物体身份与锚点；主空间先变化、辅助信息后进入；严格使用同一套时长/缓动在正反方向执行。
- 低配/无 WebGL/reduced-motion 的可用降级体验。

用状态机驱动 Scene、Camera、Animation，而非零散 setTimeout。保证真实透视、可解释的光照、合理材质与摄像机路径；避免无意义自转、粒子和发光。

交付实际可运行交互、场景/输入架构、真实浏览器证据和性能限制。
