# Prompt 05 — 精密金融与数据工作台

把当前界面升级为专业数据终端的设计语言：白底/暗底遵循项目偏好，克制、精密、读数优先，数值严格对齐。

首页不能成为功能货架；功能分组、状态层级和常用操作入口必须明确，专业数据密度不能靠全部隐藏解决。点击操作要有快速反馈与错误恢复，常见操作尽量 2～3 次可达。

重点不是炫技，而是帮助用户识别**最新状态、历史变化、风险信号、下一操作**。

- 图表/时间周期切换时，标的、数据来源、时间范围、关键参考位保持一致。
- 仅因用户主动选择、切换或请求而进行必要的可逆微动效；页面初始无自动入场、背景无呼吸粒子；自动行情刷新仅更新真实数值/状态，不启动装饰动画。不能将模拟数据伪装成实时数据。
- 明确区分实时数据、历史回放、最近成功快照和请求失败。
- 让筛选、详情展开、异常说明、数据刷新形成有逻辑的反馈。
- 保留高信息密度；禁止背景粒子、喧宾夺主的 3D 和无意义长动画。
- 提供错误、缺失字段、延迟、空数据状态。

遵循项目 AGENTS.md；先查现有系统再修改，并提供可复现实测结果。
