# Impeccable 参考能力整合说明

源自用户提供的 `aiLearn.rar` 中 `.codex/skills/impeccable/SKILL.md` 与相关 Markdown reference，按其技能分类做设计能力映射。

| 来源参考领域 | 归入本脚手架 | 使用时机 |
|---|---|---|
| `shape`, `init`, `new-work`, `document` | `DESIGN_SYSTEM.md`, `AI_LEARN_KNOWLEDGE_ARCHITECTURE.md` | 项目任务、视觉方向与设计上下文 |
| `typeset`, `layout`, `colorize`, `bolder`, `quieter`, `distill` | `DESIGN_SYSTEM.md`, `UX_FOUNDATIONS.md` | 排版、节奏、去 AI 味和视觉层级 |
| `animate`, `delight` | `MOTION_SPEC.md`, 104 场景规范 | 动效编排与微交互 |
| `critique`, `audit`, `polish`, `optimize`, `harden` | `VISUAL_QA.md`, `RELEASE_CHECKLIST.md` | 可用性、可访问性、性能和视觉检查 |
| `adapt`, `onboard`, `clarify` | `UX_FOUNDATIONS.md`, `INTERACTION_BLUEPRINT.md` | 移动端、可发现性、文案与引导 |

## 分发边界

本脚手架在 `references/impeccable-extracted/` 保存了用户提供的相关文本参考副本；**不**包含其自带 Windows 执行程序、运行器和多平台安装包，也不尝试自动执行其启动命令。它与本项目的三项新 Codex Skills 相互独立；不构成对第三方软件的安装或授权声明。
