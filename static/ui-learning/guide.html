AI Learn Studio · 使用说明

左边选择模块和场景，中间观看交互预览，右边一键复制 Codex Prompt。内置 104 条场景规范 + 2 条原 aiLearn 设计案例 + 2 套五维 AI 解析模板。

新增知识

点「新增知识」，选择所属模块（可在左侧＋添加模块/子模块），填写标题、完整 Prompt、适用场景和参考图。内置配方不可直接覆盖；可点击「复制为新知识」后修改。

备份与迁移

主工作台的知识、模块、图片、收藏和进度保存在新登账户数据库；请以顶部同步状态为准。点击「备份数据」生成 JSON（包含自建图片），换电脑可用「导入知识」恢复。原 aiLearn 的 cases.json 也可以导入文本案例，但浏览器 IndexedDB 中的原图不会自动随 JSON 转移。

安装 Codex Skills

以下脚本位于你提供的原始压缩包目录中，不由网站自动执行。

python install.py --target "D:\my-project" --mode existing --upgrade-managed --with-learning-site

然后在 Codex 中请求 $creative-frontend-director、$interaction-recipe-executor 或 $ailearn-knowledge-curator。从本站导出的单项 Skill 保存为目标项目 .agents/skills/<slug>/SKILL.md。

导出多条自建知识为 Skill

python tools/sync_knowledge.py --input ai-learn-knowledge-backup.json --output D:\my-project --dry-run

确认无误后去掉 --dry-run。默认不会覆盖已有 Skill。

限制

学习资料的账户同步需要联网，演示是交互原理教学，不代表 104 个配方全部已经实现为组件。正式项目应按真实数据、可访问性、性能和异常状态进行验收。单张图片最大4MB，账户资料总量上限20MB。发生冲突时，先导出当前资料，再重新读取账户资料并导入合并。旧版案例站使用独立本地存储，不自动同步到新登账户。
