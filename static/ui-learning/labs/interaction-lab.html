03 / METHOD

状态连续，
物理有度。

01 / 用户驱动
滚动进度本身决定导航尺寸；不监听过线后突然变成另一档。

02 / 不抢内容
导航变窄不挤压正文。滚动时仅合并一次写操作。

03 / 无障碍
键盘和减弱动态效果仍可完成同一操作。

数值可用开发者工具验证：滚动 0 / 25 / 50 / 75 / 100px 对应导航 80 / 74 / 68 / 62 / 56px。
