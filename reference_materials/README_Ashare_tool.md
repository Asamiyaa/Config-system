# A股板块轮动与ETF自动跟踪工具

## 1. 这套工具会做什么

- 自动拉取观察池ETF的历史日线，计算1/5/20/60日收益、20/60日均线、相对沪深300强弱、成交额活跃度、20日年化波动和60日回撤。
- 自动拉取全市场涨跌宽度、涨停/炸板/跌停股池，估计市场情绪、最高连板高度与整体风险状态。
- 尝试抓取财经新闻与龙虎榜，按ETF主题关键词映射；对政策、产业、盈利/订单新闻进行弱监督关键词打分。
- 输出每只ETF的八维分数、生命周期状态、风险扣分、建议仓位、动作、分数依据、数据质量。
- 根据市场状态确定组合权益仓位上限，按单只ETF和主题分组上限分配目标仓位。
- 每次盘后运行会更新“总览、ETF评分、市场情绪、涨停梯队、龙虎榜、政策新闻、历史行情”，并向“历史跟踪”追加当日快照。
- 盘前可只更新新闻；盘中可只更新行情快照，不会让盘中价格误导收盘评分。

> 注意：这不是自动交易程序，不会自动下单。免费数据源可能延迟、限流、返回空表或调整字段；脚本会标记异常。政策新闻/盈利分是关键词代理，不代替公告原文、财报、估值与产业链核验。龙虎榜是个股层面信息，不等同ETF净流入。

## 2. 安装

1. Windows 64位电脑安装 Python 3.11 或以上版本（推荐 3.12/3.13）和 Microsoft Excel 桌面版。
2. 确认 `A股板块轮动_ETF自动跟踪.xlsx`、`daily_update.py`、各 `.bat` 文件在同一个文件夹。
3. 双击 `install.bat`。安装需要网络。
4. 首次运行前关闭该Excel文件，避免文件被占用。

## 3. 每日怎么运行

| 时间 | 运行方式 | 更新内容 | 用途 |
|---|---|---|---|
| 盘前 08:30—09:20 | 双击 `premarket_news.bat` | 新闻关键词、可能关联板块、正负面标签 | 盘前做政策/产业催化核验；不更新评分与仓位 |
| 开盘后/盘中 | 双击 `intraday_snapshot.bat` | ETF现价、日涨跌幅、成交额快照 | 观察盘中行为；不重算日线信号 |
| 收盘后 15:20—17:30 | 双击 `daily_update.bat` | 全量行情、情绪、连板/炸板、龙虎榜、新闻、评分、目标仓位与历史记录 | 这是每天必须运行的一次 |
| 每周五盘后 | 先运行盘后更新，再看“历史跟踪” | 评分排名与权重变化 | 复盘评分有效性、主题重叠、错误信号 |
| 每月末 | 看“数据字典”和宏观/政策原文 | 复核政策、产业周期和评分假设 | 根据实际验证调整观察池/权重，不为单次行情随意改规则 |

## 4. 自动定时执行（Windows任务计划程序）

建议先手动成功运行三种模式，再设置定时任务。工具包提供 `setup_schedule.ps1`，可尝试自动创建以下4个工作日任务：盘前新闻 08:45、盘中快照 10:15、盘中快照 14:30、盘后全量更新 15:35。

- 使用方式：先确保 `install.bat` 安装成功；在工具目录打开 PowerShell，执行 `powershell -ExecutionPolicy Bypass -File .\setup_schedule.ps1`。如果系统策略禁止脚本或创建任务失败，请改用下方的 Windows“任务计划程序”手动配置。
- 手动配置时：盘前参数填写 `"完整路径\daily_update.py" --premarket`；盘中参数填写 `"完整路径\daily_update.py" --intraday`；盘后参数填写 `"完整路径\daily_update.py"`，并将“起始于”设置为工具所在文件夹。
- 为使用 Excel COM 自动写入工作簿，任务计划选择“仅当用户登录时运行”；运行时请关闭目标工作簿，且确保本机没有弹出 Excel 模态对话框。不要以无人登录的后台服务方式启动 Excel。
- 定时任务脚本没有在当前环境的 Windows 任务计划程序中实测；创建后请在“任务计划程序”查看历史记录，并先手动验证每个任务。盘中快照不建议高频运行，免费数据源可能限流。

## 5. 怎么看分数、状态和仓位

“ETF评分”中的权重为：宏观/市场15、政策/产业新闻15、生命周期15、量价形态15、资金活跃度15、市场情绪10、龙虎榜/梯队5、盈利/产业景气代理10，总计100；风险扣分从总分扣除。具体口径见“数据字典”。

- 80分以上：高分观察，不代表自动买入。需要价格结构和风险门槛同时通过。
- 65—79分：候选观察，等待突破或回踩确认。
- 55—64分：等待结构改善。
- 低于55分：低优先级；不因题材新闻单独买入。
- L3趋势主升：趋势确认后可考虑分批持有；L4高位扩散：避免追高；L5退潮/弱势：优先风险管理；L0/L1底部/蓄势：只有结构与相对强度改善后才升级。

“参数设置”中可以改组合资产规模、最大权益仓位、单只ETF上限、主题组上限、风险预算、回撤预警阈值、评分阈值，以及开/关观察池ETF。默认不开杠杆；脚本不会自动发出杠杆开仓指令。

“ETF评分”AD列“当前持仓比例%（用户填）”请按自己的真实组合维护。AC是脚本建议目标仓位，AE是目标与当前差值；AJ/AK/AL会按“参数设置”B5的组合资产规模自动换算目标配置金额、当前持仓金额和金额差额。目标仓位是风险预算参考，不是必须立刻调仓的命令。每次运行日志保存在工具目录下的 `logs\YYYYMMDD.log`。

## 6. 数据源与限制

- AKShare项目及安装：<https://github.com/akfamily/akshare>
- ETF历史日线接口文档：<https://github.com/akfamily/akshare/blob/main/docs/data/fund/fund_public.md>
- 行情、涨停/炸板、龙虎榜、资讯接口目录：<https://github.com/akfamily/akshare/blob/main/docs/tutorial.md>
- ETF历史行情主要源：东方财富；资讯聚合源可能包括财联社、东方财富、新浪、同花顺等，具体取决于AKShare接口版本与当时可用性。

自动化策略局限：
1. 数据抓取使用免费公开接口，无可用性承诺；需定期升级AKShare。
2. 市场涨跌宽度与龙虎榜/涨停股池并非交易所官方统一口径；脚本显示的状态适合作为筛查，不是监管事实的最终依据。
3. 成交额/20日均值只是资金活跃度代理，不等于净流入；ETF真实份额/申赎、机构持仓或资金流向可能无法免费稳定获取。
4. 关键词算法可能漏掉隐含语义、误判“利好/利空”或重复新闻。监管、减持、异常波动、制裁与行业政策请以交易所/证监会/部委公告原文为准。
5. 免费财经新闻接口不是完整的美中产业映射数据库。它只能辅助发现线索，不能自动证明某家中国企业是美国供应链的确定受益者；关键链条仍需核验客户、订单、收入、利润和估值。
6. 评分阈值和仓位逻辑是待回测的规则初稿，应先纸面记录或小仓验证，再根据至少数十个交易日的结果优化。

## 7. 常见故障

- “无法导入 pywin32”：在工具目录运行 `python -m pip install --upgrade pywin32`。
- “无法创建 Excel/Excel COM”：确认已安装桌面版 Microsoft Excel，不是只有WPS；检查Excel没有被系统策略禁用自动化。
- “行情接口失败/部分数据缺失”：升级 `python -m pip install --upgrade akshare`，确认网络可访问相关数据站；稍后重试。不要把缺失数据视为0分。
- Excel提示文件被占用：关闭所有Excel窗口后重试。
- ETF代码或基金名称需再次核实：以券商软件的最新交易代码、跟踪指数、成交额、买卖价差和折溢价为准；不要仅凭板块名字交易。
